# DeskOS 小 App 路線圖

DeskOS 的核心只負責首頁、應用程式管理、設定、導覽、事件派送與本機資料持久化。日常功能以小 App 提供，讓使用者可以依需求加入或移除；功能資料在移除後預設保留。

## 已完成：v0.4 外掛平台

- 不可變 `PluginSpec`、`PluginMetadata`、`PluginContext` 與事件介面
- 內建 App 與第三方 App 共用登錄流程
- 透過 `deskos.plugins` Python entry point 探索第三方外掛
- SQLite 保存加入狀態與 App namespaced settings
- 動態且可捲動的觸控導覽
- 原生應用程式管理與設定頁
- 時鐘、天氣、科技快訊、專注、裝置監測完成模組化
- 單一外掛探索／載入錯誤不阻止 DeskOS 啟動

## v0.5：日常資訊 App

### Weather Forecast

- 未來 12 小時溫度與降雨
- 3～5 日高低溫
- 日出、日落與紫外線
- 清楚顯示資料時間、離線狀態與最後成功快取

### Calendar

- 第一階段讀取本機 `.ics`
- 首頁只提供最近 2～3 個行程摘要
- CalDAV 另行設計授權與秘密儲存，不放進一般設定資料

## v0.6：個人節奏 App

### Focus Insights

- 今日／每週專注次數與總分鐘數
- 25／5、50／10 與自訂節奏
- 完成提示音與本機桌面通知
- 統計資料只保存在本機

### Display Routine

- 閒置後降低亮度
- 可設定喚醒與夜間時段
- 觸控滑動切換 App

## v0.7：裝置維護 App

### System History

- CPU、溫度、記憶體的 1 小時與 24 小時趨勢
- 使用低頻聚合資料，避免高頻寫入 SQLite
- 過熱、磁碟空間不足與網路中斷提示

### Diagnostics

- 天氣、RSS、SQLite、OpenGL 與網路健康狀態
- 顯示最後成功更新時間
- 手動重新整理與安全的本機資料備份／重設

## 硬體外掛

風扇、螢幕亮度與 GPIO 感測器各自做成獨立 App，不放入 DeskOS 核心。每個硬體 App 必須：

- 明確宣告支援的板子、介面與腳位
- 在寫入硬體前驗證權限及安全範圍
- 提供僅監測模式與可復原的預設值
- 不假設所有 Raspberry Pi 使用相同風扇或顯示器

## 外掛商店邊界

DeskOS 的「應用程式」頁只負責加入或移除已安裝的外掛。網路下載、套件簽章、相依套件管理與更新信任鏈尚未完整設計前，不會在介面內執行 `pip`、shell 指令或任意遠端程式碼。
